# Журнал изменений

## Текущая поставка

Каждый пункт ниже относится к текущей версии проекта, а не к ранее опубликованному варианту.

- **Добавлено сейчас:** локальное хранилище SQLite через `aiosqlite` и асинхронный
  SQLAlchemy 2.0 вместо PostgreSQL.
- **Добавлено сейчас:** автоматическое создание `bot_database.db` при первом запуске.
- **Добавлено сейчас:** хранение JSON-полей расчетов в колонках `TEXT` с явными
  `json.dumps()` и `json.loads()`.
- **Добавлено сейчас:** автоматическое удаление старых расчетов — у каждого пользователя
  остаются только пять последних записей.
- **Добавлено сейчас:** команда `/history`, показывающая до пяти последних расчетов
  текущего Telegram-пользователя.
- **Добавлено сейчас:** команда `/history <ID>` для просмотра сохраненного подробного отчета.
- **Добавлено сейчас:** обязательная проверка `telegram_id` при открытии отчета, исключающая
  просмотр расчетов другого пользователя.
- **Добавлено сейчас:** регистрация history-роутера в общем aiogram-диспетчере.
- **Добавлено сейчас:** автоматическая инициализация и корректное асинхронное закрытие
  SQLite engine в жизненном цикле приложения.
- **Добавлено сейчас:** зависимости `aiosqlite` и SQLAlchemy 2.0; зависимости PostgreSQL
  исключены.
- **Добавлено сейчас:** Windows PowerShell-инструкция по установке, запуску, получению
  токенов, резервному копированию SQLite и устранению неполадок.
- **Добавлено сейчас:** тесты ограничения истории пятью записями, JSON round-trip,
  разделения пользовательских историй и защиты от просмотра чужого расчета.
